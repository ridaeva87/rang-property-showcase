# Аналитические события RANG

События содержат только технический контекст, необходимый для административных показателей. Пароли, токены, документы и тексты сообщений не сохраняются.

| Событие | Когда создаётся | Источник | Контекст | Показатель |
|---|---|---|---|---|
| `premise_view` | Открыта публичная карточка помещения | `rangpro.ru` | помещение, объект | Просмотры и популярные помещения |
| `premise_cta` | Нажата основная CTA карточки | `rangpro.ru` | помещение, название CTA | Основные CTA |
| `favorite_add` / `favorite_remove` | Изменено избранное | `rangpro.ru` | помещение | Добавления в избранное |
| `service_view` | Открыт раздел услуг | `rangpro.ru` | без персональных данных | Интерес к услугам |
| `service_cta` | Нажата CTA конкретной услуги | `rangpro.ru` | идентификатор/название услуги | Востребованность услуг |
| `portal_login` | Успешный вход арендатора | `account.login` | пользователь | Активность личного кабинета |
| `view`, `cta_click`, `internal_lead` | Просмотр рекламы, переход, подтверждённое обращение | существующий `ad_events` | рекламная карточка, CTA | Аналитика рекламы |
| `created`, изменения статуса/ответственного | Создание и обработка заявки | существующий `requests` / `request_events` | категория, объект, помещение, услуга | Аналитика заявок |

Текущие избранное и интересы также берутся из существующих `favorites` и `property_interests`; статистика не дублирует эти сущности.
