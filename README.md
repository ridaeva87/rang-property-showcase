# Rang: Space Finder

Техническое задание для Lovable: демонстрационная главная страница сайта компании «Ранг»

Создай современную демонстрационную главную страницу сайта компании «Ранг», которая занимается арендой и продажей коммерческой недвижимости.

Компания работает с 1993 года.

ВАЖНО: сейчас необходимо создать только визуальный прототип главной страницы для презентации заказчику.

На данном этапе НЕ создавать:

личный кабинет арендатора;

административную панель;

реальную базу данных;

регистрацию и авторизацию;

реальные рассылки;

backend;

Supabase;

Telegram-интеграцию;

email-интеграцию;

настоящий AI API;

другие внутренние части системы.

Главная задача — показать заказчику, как визуально может выглядеть будущий сайт компании, его стиль, основные разделы и возможности.

Все кнопки и формы на данном этапе могут быть демонстрационными.



1. ОБЩАЯ КОНЦЕПЦИЯ

Компания «Ранг» занимается коммерческой недвижимостью:

аренда офисов;

аренда складов;

комбинированные помещения «офис + склад»;

краткосрочная аренда;

долгосрочная аренда;

продажа коммерческой недвижимости;

дополнительные услуги для арендаторов;

технические работы и переоборудование помещений.

Компания работает с 1993 года.

Сайт должен быть ориентирован прежде всего на бизнес и предпринимателей, которые ищут помещение.

Это НЕ сайт жилой недвижимости.

Не использовать визуальные ассоциации с квартирами, новостройками, жилыми комплексами и риелторами.

Не делать сайт похожим на доску объявлений.

Компания должна восприниматься как собственник/управляющая коммерческими объектами организация с большой историей работы.
